# クレカ決済 Codexテスト設計資料

このフォルダの内容をBentoリポジトリのルートへ配置してください。

- `AGENTS.md` — Codexの作業ルール、安全制約、進め方
- `docs/requirements.md` — 業務要件（確定・未定・統合）
- `docs/acceptance-criteria.md` — 受け入れ条件
- `docs/test-cases.md` — テストケース初版と重点リスク

**初版はテスト設計用であり、テスト実行済みではありません。**

Codexへの開始指示例:

> AGENTS.mdとdocs内の3ファイルを読み、対象フォームと関連クラスのコードを調査してください。まず各テストIDの対象メソッド、DB依存、外部API依存、テスト可能性を補完してください。安全制約を守り、業務要件・受け入れ条件を変更せず、仕様未定の項目は保留してください。
